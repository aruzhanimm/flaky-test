This repository contains code and aggregate results derived from **ReproFlake**. The research log archive is supplied separately and is not uploaded here.

The records identify the depositor as “Dataset”. The corresponding research paper and author attribution are available at https://arxiv.org/abs/2605.21677. The exact retrieved metadata and upstream README are preserved in the original research workspace under `data/source/`.

The dataset licence text is available at https://creativecommons.org/licenses/by/4.0/. The separately held derived research material selects eligible target failures, cleans diagnostic text, replaces selected identifiers, assigns canonical repository/test identities, and adds model predictions, audit fields and evaluation results. These transformations are the work of this student project and do not imply endorsement by ReproFlake's authors.

Stack traces retain references to third-party Java projects and libraries. Their names and any underlying source-code rights remain with their respective owners. A data licence does not relicense unrelated upstream code.

The research code in this repository has no separately granted open-source licence at publication. Dataset attribution and the CC BY 4.0 terms apply to dataset material when separately redistributed; they should not be read as a licence grant for every file in this repository.
